# Launch files

A launch file starts a network game with the map, the rules, the players,
the content and the status stream already chosen, so the battle room opens
ready. It is Open Annihilation's own `.oalaunch` file, or the settings file
TA Forever writes for 3.1c's `-c`.

Both are described in [Command Line and Game Launching](../command-line.md),
with every other way to start a game:

- [Ways to launch a game](../command-line.md#ways-to-launch-a-game), with
  examples of a host, a join, TA Forever's file, options alone and a pipe;
- [Launch files](../command-line.md#launch-files): the `.oalaunch` file,
  group by group, with a full example;
- [Launch settings](../command-line.md#launch-settings): every field and
  its option;
- [The `-c` file](../command-line.md#the--c-file): TA Forever's file and
  every key 3.1c reads;
- [Standard input and pipes](../command-line.md#standard-input-and-pipes)
  and [opening a launch file](../command-line.md#opening-a-launch-file);
- [Listing what is installed](../command-line.md#listing-what-is-installed):
  `--list-content --json`.
