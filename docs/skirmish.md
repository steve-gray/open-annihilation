# Skirmish

The skirmish setup shows one row for each player place. A row reads
**Player**, **Computer** or **Open**. One row reads **Player**: that is
you. Clicking a **Computer** row makes it **Player** only when no row is
**Player**. Clicking the **Player** row makes it **Open**.

The rows stay as you left them. A campaign mission, a saved game, a
recorded game and a network game seat their own players for that match
and put your rows back when you return to the setup. Starting Open
Annihilation again shows the same rows.

A setup saved by an earlier version can name **Player** on two rows. The
load keeps **Player** on the last of those rows, the row a skirmish
starts as, and the earlier rows read **Computer**. A setup with one
**Player** is unchanged.
